Data provenance & interpretation

This is an in-browser transport simulation. The mock endpoints own the full captures; the estimator receives only admitted protobuf replies. The white reference uses the full data and never drives refinement. The aggregate shape can resolve before token identities and ranks do.

P prioritizes measured mass × log ID count. Q follows P’s partition and prioritizes mass × clipped width spread; it can stop below its cap when further Q alone cannot improve the current P groups. Decreasing a budget discards client knowledge and replays from zero.
